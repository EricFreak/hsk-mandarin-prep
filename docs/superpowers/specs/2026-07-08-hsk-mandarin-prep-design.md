# HSK 中文备考产品 · 设计文档 (Spec)

- 日期: 2026-07-08
- 状态: Draft — 待用户评审
- 创始人: 单人, 无企业背书
- 产品形态: 自服务 Web 网站 (无真人直播)

## 1. 概述 (Overview)

面向 **HSK / 来华留学考试人群**的 **AI 驱动中文备考网站**。以官方 HSK 3.0 大纲为数据骨架, 用 AI 自适应练习引擎替代手写全套课程, 单人 30-60 天可上线付费 MVP。

一句话定位: **"对齐官方 HSK 3.0 大纲的 AI 自适应备考引擎——单人可启动、自服务、按结果付费。"**

- 旗舰: HSK 3 级付费产品
- 漏斗: HSK 1-2 免费练习
- 语言: 英文 UI 先行

## 2. 为什么是这个方向 (Why)

目标人群综合评分 **27/30** (HSK/留学) vs 华裔子女 22 / 兴趣休闲 16 / 商务职场 16。选择理由:

- **高意图 + 高付费**: 考试与留学是刚需, 按结果付费, ARPU 远高于兴趣人群。
- **获客最精准**: 用户主动搜索 "HSK prep / HSK 3 / 学中文留学", SEO + 内容营销直接命中, CAC 低。
- **最契合自服务网站**: 自适应练习、模考、AI 陪练均为自服务, 初期无需真人直播, 单人可跑通。
- **真实市场空白**: HSK 3.0 改版后新大纲资料稀缺, 现有 APP 多为旧教材翻新, AI 个性化备考 underserved。

市场数据 (2024-2026):
- 全球活跃中文学习者/使用者 > 2 亿 (教育部 2024)
- 2024 HSK 付费考生 ~72 万 (YoY +15%); 2025 上半年 41.4 万 (+19.6%); 累计考生 > 850 万
- 2024-25 在华留学生 38 万; HSK 考点 168 国 1477 个
- 越南 HSK 考量全球第一 (14.6 万)
- 中文学习市场 ~$7.4B, 预计 2027 翻倍

来源: 教育部 / 汉考国际 / 光明日报 / China Daily / Duolingo 2025 报告 / HolonIQ。

## 3. 目标用户 (Target Users)

- **主要 (付费旗舰)**: 为考 HSK 3-4 级、申请来华留学/奖学金/就业的英语圈学习者, 16-30 岁, 高意图。
- **次要 (免费漏斗)**: HSK 1-2 入门与兴趣试探者。
- **后续扩展**: 越南语 / 泰语本地化 (高量、低竞争市场)。

## 4. 两大约束的解法 (Constraints & Solutions)

### 4.1 个人无企业背书
策略: **借官方权威, 非自称权威**。考试备考是 D2C 市场, 学习者只关心"是否对真考准、是否便宜、有没有人考过、能不能验证"——这四点单人全能证明。

- 权威对齐: 精确映射官方 GF0025-2021 标准 + 官方样卷, 逐项标注出处。
- 内容即凭证: 免费 SEO 内容 + 免费模考即时出分, 让用户亲自验证质量。
- 透明 + 结果信号: 公开通过率 / 真实评价 / 真人个人品牌 / 包过退款。
- 二期: 免费 Discord 社群 + 与独立 HSK 1v1 导师分销合作 (人格化背书)。

### 4.2 需要一整套适配大纲的课程
策略: **不手写全套; 用"骨架 + 引擎 + 锚点"**。手写 1-9 级完整课程是杀死单人创始人的陷阱。

- **数据骨架**: 官方 GF0025-2021 大纲 (音节/汉字/词汇/语法, 按级量化) 编译成结构化数据。
- **核心产品 / 差异化**: AI 自适应练习引擎 + TTS 听力 + AI 写作/口语评分 + 弱项诊断。
- **质量锚 + 营销**: 旗舰级 (HSK 3) 手写精修 10-20 节核心课。
- **可信度锚**: 链接 chinesetest.cn 官方样卷 + 按官方题型自创原创模考 (即时出分)。
- **QC 飞轮**: 少量人工审核的"金标准"题库校验 AI 出题 + 用户报错通道。

**版权红线**:
- 可以: 用官方大纲事实性词汇/语法/汉字列表作骨架; 链接官方样卷; 按官方题型自创原创题; 自写讲解与学习路径。
- 不可: 复制《HSK 标准教程》教材 (北语社, 受版权保护); 抓取/复用 HelloChinese、SuperTest 等 APP 内容; 把官方真题/样卷重新分发为自有; 照抄 GF0025-2021 标准释义原文 (可引事实, 不抄表述)。

## 5. 产品架构 (Architecture)

- **数据层**: HSK 1-6 大纲结构化数据 (音节/汉字/词汇/语法, 按级, 含累计指标); 官方样卷索引; 用户进度与错题。
- **引擎层**: AI 出题 (LLM 生成 + 人工/金标准校验) + TTS (听力) + ASR (口语, 二期) + LLM 评分 (写作) + 自适应推荐。
- **内容层**: 精修核心课 (旗舰级) + SEO 指南文章 + 「HSK 2.0 vs 3.0 导航」英雄页。
- **产品层**: 词卡 SRS、分级练习、官方题型模考 (即时出分)、弱项看板、进度追踪。
- **变现层**: Freemium 付费墙 (模考 / AI 评分 / 无限练习)。
- MVP 只实现 HSK 1-3; 4-6 与高等 7-9 为后续。

## 6. MVP 范围 (30-60 天)

**In scope**:
- 编译 HSK 1-3 大纲数据。
- 词卡 SRS (1-3 级)。
- AI 生成分级练习 (cloze / 句子 / 阅读), HSK 3 为重点。
- 1 套官方题型模考 + 即时出分 (HSK 3)。
- 弱项看板。
- 每级 5-10 篇核心指南 (SEO) + 「HSK 2.0 vs 3.0 导航」英雄页。
- Freemium 付费墙 + 订阅 ($8-12/月)。
- 英文 UI, Web responsive。

**Out of scope (YAGNI, 后续)**:
- HSK 4-6 与高等 7-9。
- 口语 ASR 评分 (MVP 先做写作 AI 评分, 口语二期)。
- 多语言 UI (越南语 / 泰语)。
- 来华留学申请咨询 upsell。
- 社群 + 导师分销。
- 移动 APP (先 Web)。

## 7. 商业模式与定价 (Business Model)

- **Freemium 订阅**: 免费 (每日限量练习 + 词卡) → 付费 $8-12/月 (无限练习 + 模考 + AI 写作评分 + 弱项深度报告)。
- **按级课程包 (一次性)**: 旗舰 HSK 3 精修课 $29-49。
- **年付折扣**。
- **后期 upsell**: 来华留学申请咨询 (高客单, $数百-千)。
- **单位经济**: 自服务, 边际成本低; 主要变动成本 = AI token (按用量) + TTS; CAC 低 (SEO/社区)。

## 8. 冷启动获客 (GTM)

- **SEO**: "HSK 3 prep" "HSK vocabulary" "HSK 2.0 vs 3.0" "how to pass HSK 3" 等长尾。
- **社区**: Reddit r/ChineseLanguage、HSK 论坛、Facebook 中文学习群。
- **短视频 / 评论输出**: YouTube HSK 教学频道评论区价值输出、小红书 (侨民)、TikTok。
- **英雄内容**: 「HSK 2.0 vs 3.0 导航」(解决过渡期困惑, 顶级 SEO + 权威人设第一块基石)。
- **转化钩子**: 免费模考出分后给"弱项报告 + 针对练习", 设付费墙。

## 9. 里程碑 (Milestones)

- **W1-2**: 选品确认 + 编译 HSK 1-3 大纲数据 + 域名 / 落地页。
- **W3-5**: 词卡 SRS + AI 练习引擎 + HSK 3 模考 + 弱项看板。
- **W6-7**: 5-10 篇核心指南 + 2.0 vs 3.0 导航 + 付费墙。
- **W8**: 内测 (Reddit/社区招募 20-50 人), 收集报错与反馈。
- **W9-10**: 公开上线 + 冷启动内容分发。

## 10. 风险与未决问题 (Risks & Open Questions)

- **AI 出题质量**: 需人工金标准 + 报错飞轮; 考试内容须准确, 错题损害信任。
- **HSK 2.0→3.0 过渡**: 官方考试实际采用进度不一, 需持续跟踪 chinesetest.cn, 产品需兼容说明。
- **单人产能**: 须严格聚焦 MVP, 抗拒"完整课程"陷阱。
- **支付 / 合规**: 跨境收款 (Stripe / Paddle), 用户数据合规。
- **未决**:
  - 创始人中文水平 / 教学经验 → 影响内容自写比例。若不足, 多用 AI 出题 + 人工审核 + 外审。
  - 是否需命题/教学资质? 判断: 不需要——产品是备考工具非官方考试, 准确性靠对齐官方 + 人工校验。
  - 技术栈选型 (待实现计划阶段确定)。

## 11. 成功标准 (MVP 阶段)

- 上线后 60 天: 1000+ 注册, 20-50 付费订阅, 至少 1 篇 SEO 文章进 Google 前 10。
- 质量信号: 用户报错率低、模考完成率高、正向好评/口碑。
- 具体数值目标待内测校准后量化。
