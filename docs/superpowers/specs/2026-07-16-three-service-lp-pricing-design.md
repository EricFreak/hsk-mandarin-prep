## 1. 一级分类的转变（本设计的核心）

**旧：** 考试日期决定用户属于哪一档（standard / compressed / exam_sprint），Freemium 叙事绑在「剩余周」上。

**新：** 用户先选**要买的结果**；日期只是部分服务的输入参数。

| 服务 | 购买意图 | 谁决定内容 | 日期的角色 |
|------|----------|-----------|-----------|
| **Fixed-cycle Coach** | 固定周期系统提升（日常提升或分阶段备考均可） | **系统**（按诊断） | 不参与——按 4/8/12 周固定周期 |
| **Exam Custom** | 指定考期、自定义交付 | **用户**（五维比例/题量），系统校验可完成性 | 必填；决定校验窗口 |
| **Emergency Sprint** | ≤6 天紧急援助 | 系统（诊断突击） | 必填且 D≤6 |

已确认的边界（问答锁定）：

- Coach 包 vs Exam Custom 的区分 = **系统主导 vs 用户主导**（选项 A）
- Coach 包覆盖「日常提升 + 分阶段备考」两种动机
- 服务选择时点 = **先按目标选服务 → 再诊断 → 系统给最终方案/报价 → 可返回换服务**

## 2. 共同免费可信度链（三服务共用）

```text
选服务目标
→ 免费诊断（不计免费模考额度）
→ 完整 AI 报告
→ 完整课程大纲 + 总工作量 + 一次性报价
→ 1 天可执行样例任务
→ 锁定任务的个性化预览（可看不可做）
→ 用户确认购买（Sprint 首次免费则直接开始）
```

要点：

- 报告**完整**给出（不再截断）——报告本身是主要信任钩。
- 样例日真实可做；这替代了旧方案「免费整个 Week 1」的信任仪式，成本更低、链路更短。
- 付款前用户已看到：内容全貌、总价、样例体验、个性化预览。**不存在付款后才知道买了什么。**

## 3. 统一价值单位：Learning Point（LP）

### 3.1 定义

- 每类任务有**内部成本权重**（LP/单位）。示意值，实施前按真实 AI/资源成本校准：

| 任务类型 | 权重（示意） |
|----------|--------------|
| 词汇/语法练习 | 1 LP/题 |
| 听力题 | 2 LP/题 |
| 阅读段落组 | 3 LP/组 |
| 写作 + AI 精批 | 80–100 LP/次 |
| 模考段 + 报告 | 40–60 LP/次 |

- 全产品**单一费率 ρ（美元/LP）**。禁止按服务/紧急程度调 ρ（继承「不趁火打劫」「单一费率」底线）。
- **扣费时点 = 购买那一刻**（一次报价、买断制）。执行中做题**不**扣费——避免计量焦虑与行为扭曲。
- 权重表是内部成本模型：对用户展示「本包含 N 道听力、M 次写作精批…… 总价 $Z」，**不逐题曝光单价**。

### 3.2 三服务报价

| 服务 | 价格公式 | 用户体验 |
|------|----------|----------|
| Fixed-cycle Coach | 固定 LP 预算 × ρ → **4/8/12 周三个固定价** | 明码三档；同周期同 LP 总量（组成因诊断而异）→ 同价同货 |
| Exam Custom | Σ(所选任务×权重) × ρ → **生成前一次报价** | 调整比例/题量时报价实时更新；系统校验考前可完成，超载时要求减量或改期，禁止暗改 |
| Emergency Sprint（再次） | 同一公式（小 LP 量） | 一次报价；**无加急溢价** |

### 3.3 公平性（回应「A 30 天 / B 50 天」问题）

- 用户买的是 **LP 量**，不是日历时间 → 不同备考跨度的用户不再共享一个「月费桶」。
- 同价必同 LP 总量；单价 ρ 全场一致、可审计。
- 五周大账单劝退问题的解法：Exam Custom 里用户可**自行减量**（少配任务 → 价格立降）；Coach 包提供 4 周小包作低承诺入口。

## 4. Emergency Sprint（Freemium 善意窗）

- 条件：距考 **D ≤ 6**（含今天考）。
- **每账号 lifetime 一次**完整免费：诊断 + 完整报告 + 单窗突击包全部给满。戳：`free_sprint_used_at`。
- 结束时建议用户「后续考试出于自身利益提前规划」——引导 Coach 包 / Exam Custom，**不做硬转化墙**。
- 再次进入 Sprint：可购买，按本次加权工作量一次报价（同一 ρ），无加急费。
- 防刷：`free_sprint_used_at` 不因 Custom replan / 改期重置；多账号绕过 MVP 接受。

## 5. 任务预览机制（付费意愿钩子）

原则：**预览必须引用该用户自己的诊断结果**；泛泛功能列表不算预览。

1. **样例日**：第 1 天任务免费真实可做。
2. **锁定预览卡**（大纲内 3–5 张）：
   - 弱项点名卡：「你的听力弱项『数字与时间』→ 第 3 周 24 题高频错型专练」
   - 写作精批样例：展示**他人**批改效果（红线批注 + 提升轨迹），不虚构本人结果
   - 预测卡：「按计划完成后预计听力 54→72」——必须可解释，不吹牛
3. 点击锁定任务 → 任务详情 + 「已包含在你的 8 周包」→ 回报价页。可看不可做。

## 6. 用户旅程（端到端主叙事）

```text
注册 → 选服务目标（Coach 包 / Exam Custom / 紧急 Sprint）
  → 免费诊断 → 完整报告
  → ┬─ Coach 包：系统生成 4/8/12 周方案 + 固定价 → 样例日 + 预览 → 购买 → 执行
     ├─ Exam Custom：用户配五维/题量 → 系统校验考前可完成 → 一次报价 → 样例日 + 预览 → 购买 → 执行
     └─ Sprint：D≤6 校验 → 首次免费给满（else 一次报价）→ 执行 → 建议提前规划
  → 执行期：买断制，做题不扣费；Dashboard 为家
  → 改念：Custom replan 整单替换（未消耗 LP 处置见实施计划）
  → Sign out / in：按 DB 恢复
```

服务间切换：诊断后、购买前可返回换服务（诊断结果复用，不重考）。
